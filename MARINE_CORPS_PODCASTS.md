## 🔍 How to Find Missing RSS Feeds

### Method 1: Apple Podcasts Lookup API
For podcasts on Apple Podcasts, use:
```bash
https://itunes.apple.com/lookup?id=[APPLE_PODCAST_ID]
```
The response JSON will contain a `feedUrl` field with the RSS feed.

### Method 2: Check Podcast Websites
Many podcasts list their RSS feed on their official website, usually in:
- Footer
- Subscribe section
- About page

### Method 3: Podcast Directories
- **Podchaser** - Often shows RSS feeds
- **Listen Notes** - Can extract RSS from most podcasts
- **GetRSSFeed.com** - RSS feed finder tool

### Method 4: Hosting Platforms
Common patterns:
- **Libsyn:** `https://[name].libsyn.com/rss`
- **Spreaker:** `https://www.spreaker.com/show/[ID]/episodes/feed`
- **Anchor:** `https://anchor.fm/s/[ID]/podcast/rss`
- **Acast:** `https://feeds.acast.com/public/shows/[ID]`
- **Simplecast:** `https://feeds.simplecast.com/[ID]`

## 📝 Adding New Podcasts

### Step 1: Find the RSS Feed
Use the methods above to locate the RSS feed URL.

### Step 2: Edit the Aggregator
Open `/src/aggregators/enhanced_aggregator.py` and add to the `PODCAST_FEEDS` dictionary:

```python
PODCAST_FEEDS = {
    # ... existing feeds ...
    'New Podcast Name': 'https://rss-feed-url-here.com/feed',
}
```

### Step 3: Test the Feed
```bash
python3 -c "import feedparser; f = feedparser.parse('RSS_URL'); print(f'Entries: {len(f.entries)}')"
```

### Step 4: Deploy to Server
```bash
rsync -avz --exclude='.venv' --exclude='__pycache__' --exclude='.git' --exclude='data/' \
  /Users/canadytw/PycharmProjects/Jarheads.net/ \
  jarheads@162.241.218.175:~/Jarheads.net/
```

## 🎯 Filtering and Content Collection

### How Podcasts Are Filtered
The aggregator only saves podcast episodes that contain Marine Corps keywords:
- marine corps, usmc, marines, jarhead, leatherneck
- semper fi, semper fidelis, devil dog
- Marine units (MEU, marine expeditionary)
- Marine ranks and positions
- Marine equipment and operations

### What Gets Collected
For each relevant episode:
- **Title** - Episode title
- **Description** - Episode summary
- **Published Date** - When the episode was released
- **Author** - Podcast host or guest
- **Tags** - Episode categories/topics
- **URL** - Link to the episode
- **Category** - Automatically categorized as "podcast"

### Update Schedule
- Podcasts are checked every 6 hours (00:00, 06:00, 12:00, 18:00)
- Only episodes from the last 90 days are collected
- Incremental updates prevent re-processing old episodes
